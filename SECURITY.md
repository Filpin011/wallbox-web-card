# Security policy

The card sends commands (start, pause, resume, stop) to real electrical equipment through Home Assistant. Please
report vulnerabilities **privately** through GitHub: *Security › Report a vulnerability* on this repository. Do not
open public issues for security problems.

- Supported: the latest release.
- Never paste tokens, public URLs of your server or serial numbers in issues or screenshots.
- Expect a first answer within 7 days.
